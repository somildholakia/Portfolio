# Study manual PDF assets

The portfolio's study-material buttons expect these two PDF files in this folder:

- `is-lab-manual.pdf` — Information Security Practicals (31 pages)
- `ai-lab-manual.pdf` — Artificial Intelligence Lab Manual (43 pages)

Add the original uploaded PDFs using these exact filenames, then remove this guide file.
The React viewer opens each PDF inline in a full-screen reader; users can select and copy text from the embedded PDF viewer.
